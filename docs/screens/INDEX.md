## Common Patterns

### Screen Structure
Every screen follows this structure:
1. **ExecutiveHeader** — Global navigation
2. **Breadcrumb** — Location context
3. **ScreenHeader** — Title, KPIs, actions
4. **MainContent** — Tabs, lists, forms, charts
5. **AiDock** — AI insights and suggestions

### State Management
- **React Query** — Server state, caching, refetch
- **Zustand** — Client state, filters, selections
- **URL params** — Deep linking, shareable state

### Responsive Design
- Desktop (>1024px): Full layout
- Tablet (768-1024px): Stacked/collapsible
- Mobile (<768px): Simplified list

### Accessibility
- ARIA labels and live regions
- Keyboard navigation (Tab, Arrow, Enter, Escape)
- Screen reader announcements
- Focus management

### Telemetry
- Screen views, interactions, errors
- Performance metrics
- User behavior tracking
